## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```

### 3. Run Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```

---

## ⚡ Connecting with Supabase & Vercel

1. **Supabase**:
   - Create a project in [Supabase](https://supabase.com).
   - Set `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` in `.env` or Vercel Environment Variables.
2. **Vercel**:
   - Link repository `tarotxofficial-create/TAROT-X-OFFICIAL` in [Vercel Dashboard](https://vercel.com/new).
   - Add your Supabase environment variables in Vercel Project Settings > Environment Variables.
   - Deployments automatically trigger on each push to `main`.
